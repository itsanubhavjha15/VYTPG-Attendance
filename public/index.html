Upload Master Roster

Upload Excel / CSV file

Reads columns by name (any order): Roll Number, Name, Mobile/Contact, Email, Section, Batch. Matches common header variants like ROLL_NUMBER, STUDENT_NAME, MOBILENO, E_MAIL, SECTION_NAME, and BATCH_NAME automatically. If your file has both a Section and a Batch column, every student is saved under both — a professor can then fetch by typing either the section name (e.g. "M5M6") or the batch name (e.g. "M5") as their class name.

If your file covers multiple combinations, list the codes for students who actually take this course/subject, comma-separated. Leave blank to include everyone in the file.

Sections & Batches found in this file

Each section AND each batch is saved as its own roster, so a class only ever fetches the exact section or batch it belongs to — not the whole course. Uncheck any you don't want to save right now.

One student per line: Name, Roll Number, Contact, Email (contact/email optional).
